# Liquid Transform Navigation

Standalone preview adapted from Personal Website's navigation. Run `npm install`, then `npm run dev` and open http://localhost:5186/.

The original SVG material, morph geometry, icons, font and navigation styles are copied into this project. Only the driver changes: an eight-second loop replaces scrolling, keeps Selected Project active, and returns to the intro. The entire navigation is inert: hover, click and keyboard input cannot change the presentation.

The composition uses the Beam upload export's 593 × 473 design frame (2372 × 1892 at 4×), gray background and grid. The final 60 fps video exports and comparison preview are in `exports/final/`.
